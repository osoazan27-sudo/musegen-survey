# MuseGen music-video survey

A small static page for [MuseGen](https://www.musegen.ai): pick a world, a setting, a look and a song, and get a ready-to-paste description for your AI music video.

- Plain HTML, CSS and JavaScript — no build step, no framework, no third-party scripts.
- Analytics are off. The page writes no cookies and no localStorage.
- Every person shown is AI-generated (sample clips).
- You must be 13 or older to use MuseGen. Memberships renew automatically until you cancel in your account.

Open `index.html` through any static web server (video needs Range-request support, which GitHub Pages has).
